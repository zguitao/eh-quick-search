# E-Hentai / ExHentai 快速搜索标签

把 EhViewer 导出数据库中的 `QUICK_SEARCH` 标签带到 `e-hentai.org` 和 `exhentai.org` 网页搜索框下方，并使用 EhSyringe 同源的 EhTagTranslation 数据显示中文标签名。

## 安装

1. 浏览器安装 Tampermonkey 或 Violentmonkey。
2. 在扩展中选择“添加新脚本”。
3. 用 [`eh-quick-search.user.js`](./eh-quick-search.user.js) 的完整内容替换编辑器内容并保存。
4. 打开或刷新 E-Hentai / ExHentai 首页。

脚本用 `sql.js` 的 asm.js 版本直接在浏览器本地读取和生成 SQLite 文件。数据库不会上传到网络。

## 使用

- **导入 .db**：选择 EhViewer 导出的数据库。脚本读取 `QUICK_SEARCH` 表，合并新标签并跳过完全重复项。
- **左键点击标签**：按 EhViewer 保存的类型、分类和高级参数在当前页打开搜索结果。
- **中键或 Ctrl + 左键点击标签**：使用浏览器原生行为在新标签页打开搜索结果。
- **▾ / ▸**：折叠或展开标签列表。首次打开默认折叠，之后记忆状态。
- **自动分类**：展开后按关键词中的 `artist:`、`female:`、`language:` 等标签命名空间分组；语言条件与艺术家等条件同时出现时，以主要标签分类。语言排在最前，艺术家、团队、原作默认排在最后且折叠。管理窗口使用相同分类，第一列显示翻译后的名称，第二列显示原始搜索词。
- **汉语**：位于顶部操作区最前面；保留搜索框中已有关键词，追加 `language:chinese$` 后立即搜索；已包含该条件时不会重复添加。
- **WNACG 开关**：开启后点击标签会跳转到 WNACG 搜索。脚本会翻译显示名称或搜索关键词，因此以后手动新增的标签同样有效；同时自动清理 E 站命名空间、引号、`$` 和分页游标。
- **跳转WNACG**：搜索框内输入词后点击按钮，直接在 WNACG 搜索当前词，不受 WNACG 开关状态影响。
- **WNACG搜同名**：作品详情页“申请重命名”下方的蓝色链接；优先使用第二行原始标题，没有第二行标题时使用第一行标题。搜索前会去掉 `[方括号]`、`［全角方括号］` 和 `【方头括号】` 包住的附加词。
- **＋ 当前搜索**：把搜索框内容和当前页面的分类、高级搜索参数保存为新标签。
- **＋ 手动新增**：输入显示名称、关键词和搜索类型。
- **管理**：编辑、删除或调整标签顺序；分类标题旁可以上移、下移分类，也可以设置刷新网页后的默认折叠状态。分类设置会保存并在两个站点共用。
- **立即更新翻译**：在管理窗口中手动检查 EhTagTranslation 数据；正常情况下脚本每天自动检查一次。
- **导出 .db**：生成仅含快速搜索标签的 SQLite 数据库，可再次导入本脚本。

标签保存在脚本管理器的共享存储中，因此两个站点共用一份列表。

标签翻译沿用 [EhSyringe](https://github.com/EhTagTranslation/EhSyringe) 的更新流程：读取 `EhTagTranslation/Database` 最新 Release，再从其版本固定的镜像下载 `db.html.json`。翻译只改变按钮显示文字，实际搜索表达式保持原样。下载失败时继续使用本地缓存，并在六小时后重试。

## 支持的 EhViewer 字段

`NAME`、`MODE`、`CATEGORY`、`KEYWORD`、`ADVANCE_SEARCH`、`MIN_RATING`、`PAGE_FROM`、`PAGE_TO` 和 `POSITION`。

普通搜索、上传者、标签、热门、订阅和排行模式均可使用。导出的数据库刻意不包含原 EhViewer 备份中的浏览历史、下载记录和收藏。
